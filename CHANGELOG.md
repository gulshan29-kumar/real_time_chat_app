# Changelog

All notable changes to **QuickChat** are documented here.

## [1.0.0] - 2026-09-14
### Added
- Complete full-stack real-time chat architecture (React 19 + Express 5 + Socket.IO).
- Dark glassmorphic design system with ambient glowing mesh.
- Live user presence status with pulsing green indicators.
- Instant photo attachment and sharing via Cloudinary.
- End-to-end user authentication with JWT and bcryptjs.
- Monorepo scripts and Vercel deployment configuration.
